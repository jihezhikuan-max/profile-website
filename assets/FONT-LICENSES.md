# Font sources and licenses

- Inter: https://fonts.google.com/specimen/Inter — license: OFL-Inter.txt
- Noto Sans JP: https://fonts.google.com/noto/specimen/Noto+Sans+JP — license: OFL-NotoSansJP.txt

Downloaded from the public Google Fonts CSS API and fonts.gstatic.com on 2026-10-22. Font files are unmodified WOFF2 subsets, hosted locally. The associated unicode-range rules are preserved in fonts.css. Both families use the SIL Open Font License 1.1; full license texts are included alongside the fonts.

scripts/update-fonts.ps1 downloads only generic public resources. It does not read or transmit site content or personal information.
