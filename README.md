# 吉賀 智寛 — Profile & Portfolio

名刺のQRコードから訪れる方に向けた、HTML / CSS / JavaScriptのみの静的ポートフォリオサイトです。外部ライブラリやビルドは不要です。Inter・Noto Sans JPを同梱し、閲覧時の外部フォント接続も不要です。GitHub Pagesのリポジトリ配下で動く相対パスを使用しています。

## デザイン・構成

Editorial × Tech × Minimalをテーマに、ネイビー `#0B1220`、オフホワイト `#F6F8FC`、ブルー `#2563EB`を使用。大きなタイポグラフィ、明暗を切り替えたセクション、余白と罫線、控えめなスクロール演出で構成しています。

1. **Hero** — 大きな「吉賀 智寛」と「TOMOHIRO YOSHIGA」、キャッチコピー・所属・本文
2. **About Me** — 琉球大学での学びと305LAB・ハンドボールの活動
3. **Projects** — RYUDAIHandTrack
4. **Experience** — 企業向けAI活用支援（OJT）、AI講座の運営支援、ハンドボール部での活動
5. **Contact** — メール連絡先と305LABの活動紹介Instagram

Skillsセクションはありません。日本語本文は提供された確定原稿を使用し、英語版を別のJSONに収録しています。氏名の英字表記は本人指定の「TOMOHIRO YOSHIGA」を使用しています。活動期間、成果の数値、追加の肩書きなどは推測して掲載していません。

## ファイル構成

- `index.html`：ページの骨組み、言語切り替え、メタ情報
- `style.css`：共通のデザイントークン、レスポンシブレイアウト、文字組み、アニメーション
- `fonts.css`：同梱フォントの定義（必要な文字範囲だけブラウザーが読み込みます）
- `script.js`：翻訳JSONの読み込み、描画、言語選択の保存、スクロール演出
- `locales/ja.json` / `locales/en.json`：日本語・英語の本文と一覧データ
- `start-local.bat`：Windows用の起動ファイル
- `serve-local.ps1`：Windows標準機能で動くローカルHTTPサーバー
- `scripts/sync-static.cjs`：JSONと描画コードから、初期表示用の日本語HTMLを同期する編集用ツール
- `assets/`：本人提供の写真2サイズ、フォント、フォントライセンス
- `scripts/update-fonts.ps1`：公開配布フォントの再取得用。通常の起動時には実行不要

## ローカルで確認

### Windows：ダブルクリックで起動

1. エクスプローラーでこのフォルダーを開き、`start-local.bat` をダブルクリックします。
2. 起動したウィンドウは開いたままにします。既定のブラウザーで `http://127.0.0.1:8000/` が開きます。
3. 右上の **JP / EN** で表示を切り替えます。
4. 終了するときはサーバーのウィンドウを閉じるか、そこで **Ctrl+C** を押します。

ブラウザーが自動で開かない場合は、上記URLをアドレスバーに貼り付けてください。**`index.html` を直接ダブルクリックすると、翻訳JSONを読み込めません。** ファイルを編集したらブラウザーを再読み込みしてください。

Windows標準のWindows PowerShellと.NETを使用するため、Python・Node.jsのインストールや管理者権限は不要です。batは同じフォルダーの `serve-local.ps1` を呼び出します。実行ポリシーの指定はこの起動プロセスだけに適用され、PCの永続設定は変更しません。組織のポリシーで実行が禁止されている場合は管理者へ確認してください。

サーバーはこのPC内のループバックアドレスだけで待ち受けます。指定したサイトファイルと `assets/` 内の許可された画像・WOFF2フォントのみを配信し、一般公開はしません。`127.0.0.1` はこのPC専用のため、別のスマートフォンからは接続できません。

接続できない場合は、サーバーのウィンドウが開いているかを確認してください。ポート8000が使用中の場合は既存のプレビューを終了するか、このフォルダーでターミナルを開いて別のポートを指定します：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\serve-local.ps1 -Port 8001
```

その場合は `http://127.0.0.1:8001/` で開きます。ブラウザーを自動で開かない場合は `-NoBrowser` を追加します。補助ファイルはフォルダー名に空白や日本語が含まれていても利用できます。

### Pythonを使用する場合

Pythonがある場合は、次の方法でもローカルプレビューを起動できます：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザーで `http://127.0.0.1:8000/` を開きます。Python版は起動フォルダー全体を配信するため、プロジェクトのフォルダーから起動してください。VS CodeのLive Serverも利用できます。JSONをfetchするため `file://` は非対応です。JavaScriptを有効にしてください。

## 本文を編集・項目を追加

日本語・英語のJSONを同じ構造で更新します。本文はHTMLとして解釈せず、テキストとして表示します。

- HeroとAbout：それぞれの `paragraphs` 配列に段落を格納します。
- プロジェクト：`projects.items` 内の既存項目を複製し、タイトルと `paragraphs` を更新します。
- 活動：`experience.items` 内の既存項目を複製し、タイトルと `paragraphs` を更新します。
- 見出しやナビゲーション：対応するJSONの文字列を編集します。
- 日本語の初期ページタイトル・説明：必要に応じて `index.html` のメタ情報も更新します。

確定した日本語本文は、本人の確認なく変更・要約・追加しないでください。既存項目のフィールド構造を維持し、両言語で項目の数と順序を揃えます。

### 初期HTMLの同期（内容・描画コードを更新した後）

検索エンジンやJavaScript無効時でも内容を読めるよう、`index.html` に日本語本文を事前に入れています。JSONまたは描画コードを編集した後は、Node.jsが使える編集環境で次を実行してください。普段の閲覧・batからの起動にNode.jsは不要です。

```sh
node scripts/sync-static.cjs
node scripts/sync-static.cjs --check
```

最初のコマンドは本文・ナビゲーション・メタ情報を同期し、2つ目は同期漏れを確認します。翻訳取得に失敗しても初期の日本語本文を残し、起動方法と再試行ボタンを表示します。

JP / ENの選択は、利用可能な場合にlocalStorageへ保存されます。初回は日本語です。保存が禁止された環境でも切り替え可能です。`prefers-reduced-motion` に対応し、動きを減らすOS設定では演出やスムーズスクロールを抑えます。

## 実際の写真・スクリーンショットを追加

ハンドボールの項目には本人提供の実写真を使用しています。元の色と構図を保ち、1600×1066px（約217KB）と800×533px（約75KB）のJPEGを同梱しています。画面幅に合わせて選択し、遅延読み込みします。元の写真は変更していません。

架空の人物写真、企業ロゴ、実績画像は使用していません。初期表示のコート図はプロジェクトのテーマを表す装飾で、アプリ画面や試合データを再現したものではありません。

`projects.items[]` と `experience.items[]` の `image` に、後から本物の画像を設定できます。未設定の `src` は空文字列のままにします。

1. このフォルダー直下に `assets` フォルダーを作成し、掲載できる実際の写真やスクリーンショットを入れます。
2. ファイル名は半角英数字で始め、半角英数字・ハイフン・アンダースコアを使います。例：`handtrack-screen.webp`。
3. 日英両方のJSONで対象項目の `image` を更新します。`src` は同じパス、`alt` と `caption` は各言語で記述します。

```json
"image": {
  "src": "assets/handtrack-screen.webp",
  "width": 1600,
  "height": 1000,
  "alt": "実際の画像に何が写っているかを説明する文章",
  "caption": "必要な場合のみ画像の補足を記入"
}
```

この例は入力形式の説明です。画像の内容に合う説明に置き換えてください。`width` と `height` は実ファイルの寸法を指定してください。`caption` は不要なら空文字列にできます。ハンドボール写真では追加の `smallSrc` に幅800px版を指定しています。この機能を他の画像にも使う場合は幅800px版を用意し、`src` の幅を `width` に記載してください。適切な解像度に縮小し、可能ならWebPやAVIFで圧縮すると読み込みが軽くなります。

Windows用サーバーが配信する画像形式は `.png` / `.jpg` / `.jpeg` / `.webp` / `.avif` / `.svg` です。`assets/` 直下だけが対象で、サブフォルダー、空白や日本語を含むファイル名、外部URL、シンボリックリンク・ジャンクションは使えません。OneDriveの通常の同期フォルダーは使用できます。大文字・小文字もJSONと実ファイルで揃えてください。GitHub Pagesでは大文字・小文字が区別されます。

## デザインの調整とフォント

`style.css` 冒頭のカスタムプロパティで配色、本文・見出しサイズ、左右の余白、セクション間隔、アニメーション速度をまとめて管理します。本文はスマートフォン16px、PC17〜18px。日本語版では日本語の見出しを主役にし、英語は補助ラベルにしています。

写真は比率を保って全体表示し、PCでは説明文と横並び、スマートフォンでは縦並びになります。Projectsの青いコート図は、実際のスクリーンショットを設定すると差し替わります。

Inter・Noto Sans JPはSIL Open Font Licenseで同梱しています。出典は `assets/FONT-LICENSES.md`、ライセンス本文は同じフォルダーの `OFL-*.txt` です。フォントは公開配布されている文字範囲ごとのファイルを保存しており、本文を更新しても再取得は不要です。Google Fontsへプロフィール文章を送る処理はありません。フォントの配布版を更新する場合のみ、インターネット接続のある編集環境で `scripts/update-fonts.ps1` を実行します。

## 表示・操作の確認方法

ローカルサーバーを起動した状態で、ブラウザーの開発者ツールにあるデバイス表示を使います。実機iPhoneでの確認は別途必要です。ループバックのURLを別端末に入力しても接続できません。

- **スマートフォン**：幅375px・390px。長い見出し、メールアドレス、ナビゲーションが画面からはみ出さないこと。
- **タブレット**：幅768px・1024px。カラムの切り替えと余白を確認。
- **PC**：幅1440px。Heroの文字組みとセクション間のメリハリを確認。
- **言語**：JP → EN → JPで本文、ナビゲーション、ページタイトル、`html` の `lang` 属性が切り替わること。ENを選んで再読み込みしたときに選択を保持すること。
- **操作**：セクションリンク、Tabキーによるフォーカス、本文へのスキップリンクを確認。
- **動き**：通常のスクロールで本文が自然に表示されること。OSまたは開発者ツールで `prefers-reduced-motion: reduce` を有効にして、本文が隠れず読めること。
- **画像**：実画像を追加した場合、両言語で読み込めること、代替テキストと補足が正しいこと。
- **エラー**：翻訳JSONを取得できない場合に起動方法が表示され、JP / ENから再試行できること。
- **連絡先**：メールリンクの宛先が正しいことを確認（実送信は不要）。Instagramのリンク先と「305LAB」の表記を確認。
